
# Project 03 - Network Threat Investigation

## Project Status
Planned

## Objective
Investigate simulated suspicious network activity
using Wireshark to identify security anomalies,
analyze network traffic, and document findings.

## Tools and Technologies
- Wireshark
- TCP/IP
- DNS
- HTTP and HTTPS
- Packet Capture (PCAP)
- MITRE ATT&CK Framework

## Lab Exercises
- Capture and analyze network traffic
- Apply packet display filters
- Identify suspicious network connections
- Investigate unusual DNS activity
- Analyze simulated network threats
- Document indicators of compromise
- Recommend mitigation strategies

## Deliverables
- Network architecture diagram
- Sample packet capture files
- Wireshark analysis screenshots
- Documented indicators of compromise
- Incident investigation report
- Remediation recommendations
- Lessons learned
