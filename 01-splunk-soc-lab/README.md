
# Project 01 - SOC Threat Detection Lab

## Project Status
Planned

## Objective
Build a simulated Security Operations Center (SOC)
environment using Splunk to monitor security events,
detect suspicious activity, and investigate threats.

## Tools and Technologies
- Splunk Enterprise
- Search Processing Language (SPL)
- Windows Event Logs
- Linux Authentication Logs

## Lab Exercises
- Install and configure Splunk
- Ingest security event logs
- Detect repeated failed login attempts
- Create security detection rules
- Configure alerts and dashboards
- Investigate simulated security incidents
- Document findings and recommendations

## Deliverables
- Lab architecture diagram
- SPL search queries
- Security dashboard screenshots
- Detection rules
- Incident investigation report
- Lessons learned
