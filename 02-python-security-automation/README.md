
# Project 02 - Python Security Automation

## Project Status
Planned

## Objective
Develop a Python-based security automation tool
that analyzes authentication logs, detects suspicious
login activity, and generates security reports.

## Tools and Technologies
- Python 3
- Visual Studio Code
- Git and GitHub
- CSV and JSON
- Regular Expressions

## Lab Exercises
- Read and parse authentication logs
- Identify failed login attempts
- Extract source IP addresses
- Detect potential brute-force activity
- Establish detection thresholds
- Generate automated security reports
- Test detection accuracy and false positives

## Deliverables
- Python source code
- Synthetic authentication logs
- Automated detection reports
- Test cases and validation results
- Installation and usage instructions
- Lessons learned
